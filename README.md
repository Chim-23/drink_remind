# 喝水提醒（Windows）

工作日（周一到周五）按计划霸屏提醒喝水，支持开机自启、立即测试、自定义计划。

## 默认计划

| 时间  | 内容 |
|-------|------|
| 10:00 | 半杯，约 275 毫升 |
| 11:30 | 喝完剩下半杯，约 275 毫升 |
| 14:30 | 重新装一杯，喝半杯，约 275 毫升 |
| 16:30 | 喝完剩下半杯，约 275 毫升 |

## 使用方式

1. 双击运行 `dist\DrinkRemind.exe`（或先执行 `build.bat` 生成）
2. 勾选「开机自启动」（默认开启）
3. 点「测试霸屏提醒（立即生效）」验证效果
4. 在列表中增删改时间/文案，点「保存设置」立即生效

## 说明

- 提醒时全屏置顶，需点击「我喝了」才能关闭；可选择稍后提醒
- 关闭主窗口会最小化到任务栏，程序继续在后台计时
- 配置保存在 exe 同目录的 `config.json`
- 开发调试：`python drink_remind.py`
